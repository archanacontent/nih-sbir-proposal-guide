# Resubmission

NIH allows one resubmission of any application, and it's the only point where you can answer reviewers on the record ([NOT-OD-18-197](https://grants.nih.gov/grants/guide/notice-files/NOT-OD-18-197.html)). If the A1 fails, the project can come back as a new application. That new version may not mention earlier reviewers, respond to their critiques or show how the project has changed. Every argument you hold back from the A1 loses its context once the A1 is used.

## Reading the Summary Statement

The summary statement reaches eRA Commons after peer review, and the program official's name and contact details sit at the top. Call that person before you decide anything. NIH SEED suggests using the call to test whether the reviewers' comments are addressable, how you plan to answer them and how to fit the most important responses onto one page ([NIH SEED](https://seed.nih.gov/small-business-funding/how-to-apply/resubmission-page)).

Sort each criticism by the criterion it hits. Concerns about the Approach, such as a missing control, a thin alternative strategy or an unclear milestone, can usually be fixed with new data or a redesigned aim. Concerns about Significance or Innovation question whether the project deserves funding at all, and a one-page reply rarely changes that verdict.

## Revising or Starting Over

An A1 has to go in within 37 months of the original application. If you choose a new application instead, NIH doesn't require the science to be substantially different. It has to be formatted as new, with no Introduction, no reference to earlier reviews and no marked changes. Revise when the critique centers on execution and you can answer it with evidence. Start over when reviewers doubted the problem or the product, because a new application reaches a panel that hasn't already formed a view.

## Writing the Introduction

The Introduction is a one-page attachment. NIH SEED recommends that it thank reviewers for their comments, answer each concern raised in the summary statement and summarize the substantial additions, deletions and changes to the application. Quote or paraphrase each criticism, then state what changed and where in the application a reviewer will find it. Reviewers judge the application as now presented, taking into account your responses and the changes made ([PA-27-100](https://files.simpler.grants.gov/opportunities/d1ba49e5-3684-4420-849a-ab2330ec493e/attachments/743ad4bd-fc28-450e-9249-1008f37490af/PA-27-100-Revised-Full-Announcement.html)).

Changes stay unmarked in the body of the application. For applications due from May 25, 2024, NIH has told applicants not to flag edits with markup such as bracketing, indenting or highlighting, and to outline changes only in the Introduction ([NOT-OD-24-061](https://www.grants.nih.gov/grants/guide/notice-files/NOT-OD-24-061.html)). Before the program official call, draft the Introduction in outline form, one line per criticism, so the conversation centers on the responses that need the most space.
