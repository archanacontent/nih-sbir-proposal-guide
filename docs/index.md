# NIH SBIR Proposal Guide for Health Companies

<p class="lede">A health company with strong preliminary data can still leave an NIH review round without a score if reviewers can't follow how its aims lead to a product. Only about half the applications in each SBIR round are <a href="https://files.simpler.grants.gov/opportunities/d1ba49e5-3684-4420-849a-ab2330ec493e/attachments/743ad4bd-fc28-450e-9249-1008f37490af/PA-27-100-Revised-Full-Announcement.html">discussed and scored</a>. Since 2026, each attempt also counts against an <a href="https://grants.nih.gov/grants/guide/notice-files/NOT-OD-26-090.html">HHS limit of nine applications per company a year</a>, and NIH <a href="https://grants.nih.gov/grants/guide/notice-files/NOT-OD-26-064.html">no longer accepts a late submission</a>. An unscored application now costs a slot as well as a cycle. Decide which projects deserve those slots before drafting begins, then build each application around the criteria reviewers score.</p>
