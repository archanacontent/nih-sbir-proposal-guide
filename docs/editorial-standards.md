# Editorial Standards

These rules cover how the guide's own pages are written and sourced. None of them are NIH requirements, and NIH has no rule on punctuation in an application. The formatting rules NIH does enforce, such as font size, margins, page limits and PDF settings, are listed on the [Compliance Matrix](compliance-matrix.md) page with links to the NIH instructions.

## Voice

- **Reader** - founders, principal investigators and proposal managers at US health companies. Write as a peer who has read the notices, never as a manual.
- **Position** - tell the reader what to do and why, in the second person, and take a side where the evidence supports one.
- **Plain words** - prefer short, common words, and name the person or body that acts instead of letting a rule or a document act.

## Sources and Verification

- **Primary first** - every rule cites the NIH notice, funding announcement, SBA page or statute it comes from. Consultant analysis appears only for figures NIH does not publish, and is credited by name.
- **Read before citing** - a figure goes in only after it has been read on the source page itself, and the Sources page records when each one was last checked.
- **Superseded notices** - when NIH rescinds a notice, the guide names the replacement and marks the earlier one as withdrawn, as it does for NOT-OD-26-073.
- **Real examples only** - every award in the teardown is a funded project linked to its public record.

## Format

- **Headings** - plain Title Case, and the first sentence under a heading never repeats it.
- **Lists** - a bold label, a spaced hyphen, then the text.
- **Figures** - numbers as the source states them, with dollar amounts to the dollar where NIH gives them.
- **Scope** - each page covers one stage of the application, and no fact is explained on two pages.

## Proposing a Change

Open an issue or pull request on [GitHub](https://github.com/archanacontent/nih-sbir-proposal-guide) with a link to the source behind the change. Each pull request runs the build, link and style checks before anyone reviews it.
