# NIH SBIR Proposal Guide for Health Companies

Live site: https://archanacontent.github.io/nih-sbir-proposal-guide/

A health company with strong preliminary data can still leave an NIH review round without a score if reviewers can't follow how its aims lead to a product. Only about half the applications in each SBIR round are discussed and scored. Since 2026, each attempt also counts against an HHS limit of nine applications per company a year, and NIH no longer accepts a late submission. An unscored application now costs a slot as well as a cycle. Decide which projects deserve those slots before drafting begins, then build each application around the criteria reviewers score.
